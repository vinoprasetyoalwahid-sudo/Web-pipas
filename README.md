# MatterQuest — Simulasi Interaktif

## File utama
- `index.html`: beranda dan daftar materi. Identitas Kelompok 9 berada di bagian atas beranda.
- `materi-1.html` sampai `materi-5.html`: halaman masing-masing bab.
- `simulasi.html`: halaman khusus simulasi perubahan fisika, kimia, dan biologi.
- `quiz.html`: halaman kuis terpisah.
- `style.css`: tampilan semua halaman.
- `script.js`: data materi, kuis, dan interaksi simulasi.

## Menjalankan
Buka `index.html` di browser atau gunakan Live Server di VS Code. Pastikan semua file berada dalam folder yang sama.

## Upload ke GitHub
Upload semua file HTML, `style.css`, `script.js`, README, serta folder `images` jika kamu menambahkan gambar materi.

Catatan: enam perubahan wujud (mengembun, membeku, mengkristal, menguap, mencair, menyublim) termasuk perubahan fisika, bukan perubahan kimia. Simulasi kimia dan biologi tersedia di bagian terpisah.
